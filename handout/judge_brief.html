Provenant

A deterministic firewall between AI agents and their tools. The model can propose anything. Policy decides what runs.

01What it is

Every tool call an agent proposes goes through one policy check written in plain Python, with no model in the loop. A tool runs only under a single-use grant bound to that exact call. We assume the most gullible model possible, and the tools stay safe anyway.

IN
Any agent
Claude Code, Claude Desktop, Cursor, VS Code, any MCP client
CHECK
One deterministic gate
Provenance, injection context, shell and paths, network pinning, secrets and PII. Fails closed: an unknown tool is held for a person; a broken policy or an error means DENY.
OUT
ALLOWruns once, under a grant
DENYnever reaches the tool
REQUIRE_APPROVALwaits for a person
02What it does

Guards real tools

  • Wraps every stdio MCP server; only allowed calls get through
  • Claude Code hook: DENY blocks, approval becomes Claude's own prompt
  • Tool definitions pinned by HMAC, so a changed tool is withheld
  • Stopped real Claude Code from rm -rf ./* and reading .env with permissions bypassed

Mail securityNEW

  • Scores the email an agent reads: look-alike domains, Reply-To mismatch, link shorteners, instructions aimed at AI
  • An address copied from a phish cannot receive your data
  • High-risk mail triggers a phone alert call

Live consoleNEW

  • Every decision as it happens, read from the audit log
  • Demo runs are labelled and never counted as live traffic
  • Held calls are approved only at a terminal, never in the browser
  • Hash-chained, signed audit log; any edit is detected

A spoken alert: high-risk email, don't click, verify the sender.

LimitsNot proven yet

Paraphrase. Provenance is value-based, so a reworded address can slip that one rule. The other rules still apply.

Shell. Analysis is pattern-based; a script written then run is judged by the run command.

Remote MCP. Only local stdio servers are proxied today.

Field tests. Phone approval of held calls and the Windows one-liner have not run on real infrastructure yet.

Passing 231 cases is evidence for those cases, not proof that no bypass exists.
