04 / What the gate checks P2

Six checks. Zero model calls.

01
Provenance
An address copied from what the agent read can’t receive your data.
02
Injection context
After injected text is read, every side effect needs a human.
03
Shell and paths
Root deletes, pipe-to-shell, workspace escape, credential files.
04
Network
Private, metadata and encoded IPs. Resolve once, then pin.
05
Single-use grants
Bound to the exact call. No replay, no swapped arguments.
06
Pinned tools
A changed MCP tool definition (rug pull) is withheld.
