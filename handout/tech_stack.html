Tech stack

Provenant's core runs on the Python standard library alone: zero runtime dependencies, nothing to pip-install beyond the wheel, and no model in the decision path.

At a glance
Python 3.10+
35 modules · ~7,900 lines
0 runtime deps · 257 tests
00Layers

Four layers, one rule: every path to a real tool goes through the same deterministic check, and the security core never imports anything outside the standard library.

L1 · ENTRY
Agents

MCP clients via stdio proxy, Claude Code via hooks, our gated MCP tool server

L2 · DECIDE
Policy core

Guard + PolicyEngine in plain Python. ALLOW / DENY / REQUIRE_APPROVAL, fail closed

L3 · STATE
Proof

SQLite grants and approvals, HMAC hash-chained audit log, pinned manifests

L4 · SURFACE
People

CLI, local ops console, product site, phone alert for risky email

WhyNo deps

A firewall's own supply chain is attack surface. Keeping the core on the standard library means nothing third-party sits in the decision path, installs are offline-friendly, and every line that decides ALLOW or DENY is ours to audit.
